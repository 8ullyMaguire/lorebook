## M3.1 Filename parsers

Goal: port Calibre's `FileInfo` regex set and expose `parse_file_info` in
`lorebook-scan::filename`. Tests are table‑driven over ≥20 real filenames.

Implementation: module `filename.rs` with a public `parse_file_info(&Path) ->
FileInfo` and a `FileInfo` struct containing parsed fields. See
`tests/filename.rs` for initial tests.

Verification: run `cargo test --workspace`. The parser should produce the same
basename and extension as Calibre for the sample filenames.

Commit tag: `v0.0.1-parse-filename`.
